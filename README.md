# Cricket Player Segmentation using K-Means Clustering

## Overview
This project focuses on segmenting cricket players into different groups based on their performance statistics using K-Means Clustering. The project applies unsupervised machine learning techniques to analyze player performance patterns and identify meaningful clusters.

## Objective
The main objective of this project is to perform player segmentation analysis using cricket statistics such as batting average, strike rate, runs scored, and experience to discover similarities among players.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn

## Dataset Features
The dataset contains cricket player statistics including:
- Runs
- Batting Average
- Strike Rate
- Highest Score
- Career Span
- Experience

## Project Workflow
1. Data Loading and Cleaning
2. Feature Engineering
3. Exploratory Data Analysis (EDA)
4. Feature Scaling using StandardScaler
5. K-Means Clustering
6. Cluster Evaluation
7. Data Visualization

## Machine Learning Concepts Used
- Unsupervised Learning
- K-Means Clustering
- Elbow Method
- Silhouette Score
- Feature Scaling

## Visualizations
The project includes:
- Cluster Scatter Plots
- Elbow Curve Analysis
- 3D Cluster Visualization using Plotly

## Key Learnings
- Understanding clustering techniques
- Importance of feature scaling in K-Means
- Cluster evaluation methods
- Data visualization and interpretation
- Player performance segmentation

## Conclusion
This project demonstrates how unsupervised machine learning can be used to group cricket players based on performance metrics and extract meaningful insights from sports analytics data.
